# `.gitignore`

> Added in **patch 01** · [View the file](../../.gitignore)

## What it is for

Lists files and folders that **git must never save**. Git reads it before every commit.

## Line by line

| Line | Why it is ignored |
|---|---|
| `node_modules/` | Downloaded packages. Huge, and `npm install` recreates them from `package.json`. |
| `dist/` | Built output. Recreated by the build command. |
| `.env` | **Your secrets** (passwords, keys). Only `.env.example`, with fake values, is committed. |
| `backend/src/generated/` | Code generated by Prisma from the schema (from patch 02). Recreated by `npx prisma generate`. |
| `backend/uploads/` | Images people upload (later patches). Data, not code. |
| `.DS_Store`, `*.log` | macOS folder files and log files. |

## Rule of thumb

Commit what a human wrote. Don't commit what a tool can recreate, or anything secret.
