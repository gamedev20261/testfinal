# `backend/.env.example`

> Added in **patch 01** · Changed in **patches 02, 03**, after **06** · [View the file](../../../backend/.env.example)

## What it is for

A **template** for your personal `backend/.env` file. Settings that differ between
computers (ports, passwords, secret keys) live in `.env`, not in the code.

```bash
cp .env.example .env     # make your own copy, then edit it
```

- `.env.example` **is** committed: it shows which settings exist, with safe example values.
- `.env` is **not** committed (see `.gitignore`), because it holds real secrets.

When a patch adds settings, copy the new lines from `.env.example` into your `.env`
(or copy the whole file again, if you haven't changed anything).

## The settings

| Name | Example | Meaning | Since |
|---|---|---|---|
| `NODE_ENV` | `development` | Which mode we run in. In `production`, logs are plain JSON and later some safety options switch on. | 01 |
| `PORT` | `3001` | The port the API listens on → `http://localhost:3001` | 01 |
| `LOG_LEVEL` | `info` | How chatty the logs are. `debug` shows the most; `error` only shows problems. | 01 |
| `DATABASE_URL` | `postgresql://geo:geo_dev_password@localhost:5432/geoannotator` | Where the database is and how to log in to it ([explained](../../concepts/databases.md#5-the-connection-string)). Matches `docker-compose.yml`. | 02 |
| `JWT_SECRET` | `dev-only-secret-replace-me-…` | The key that signs login tokens ([why it matters](../../concepts/authentication.md#3-the-proof-a-jwt-json-web-token)). At least 32 characters. Make your own with the command in the file. | 03 |
| `SESSION_HOURS` | `24` | How long a login lasts | 03 |
| `ADMIN_NAME` | `Administrator` | Name of the first admin account | 02 |
| `ADMIN_EMAIL` | `admin@example.com` | Email you log in with | 02 |
| `ADMIN_PASSWORD` | `ChangeMe123!` | Password you log in with (at least 8 characters) | 02 |

### PostgreSQL installed on your computer instead of Docker

Below `DATABASE_URL` there's a commented-out (`#`) alternative:

```
# DATABASE_URL=postgresql://postgres:YOUR_POSTGRES_PASSWORD@localhost:5432/geoannotator
```

If you use PostgreSQL with pgAdmin instead of Docker, put that line (without the `#`, and
with your real password) in your `.env` in place of the Docker one. Step by step:
[local-postgres.md](../../local-postgres.md).

The three `ADMIN_*` settings are only read by `npm run db:seed`, which creates the first
admin. Changing them later does **not** change an existing account.

## Format

One `NAME=value` per line; `#` starts a comment. No spaces around `=`.
Values are always read as text; [`env.ts`](src/config/env.ts.md) converts them
(for example `"3001"` → the number `3001`).
